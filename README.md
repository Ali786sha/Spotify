Overview
This project marks my first adventure into the world of coding—building a Spotify clone. The primary objective was to replicate key features of Spotify, such as music streaming, playlist creation, and user authentication, while learning and applying new technologies along the way.

Features
Music Streaming: Stream songs from a database, similar to how Spotify functions.

Playlist Management: Users can create, edit, and delete their playlists.

User Authentication: Secure user registration and login.

Search Functionality: Users can search for songs, artists, and albums.

Responsive Design: The interface adapts to various screen sizes for a seamless experience.

Technologies Used
Programming Languages: JavaScript, HTML, CSS
Tools: Visual Studio Code, Git, GitHub
